# Школьный дневник

Первая рабочая версия.

## Уже реализовано
- расписание по дням недели;
- до 8 уроков в день;
- кнопка «Урок окончен»;
- ввод домашнего задания;
- автоматический поиск следующего урока того же предмета;
- домашка автоматически появляется на дате следующего урока;
- отметка «выполнено»;
- Android-уведомление в 18:00 за день до урока.

## Установка
1. Создай новый проект:
   flutter create school_diary

2. Замени файлами из архива:
   - pubspec.yaml
   - lib/main.dart
   - android/app/src/main/AndroidManifest.xml

3. Выполни:
   flutter pub get
   flutter run
